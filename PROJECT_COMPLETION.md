## 🎮 HOW TO TEST

### Test Service Browsing
1. Go to `/services`
2. See all services listed
3. Click on service card
4. View service details in modal
5. Click "Book Now"

### Test Booking
1. Go to `/booking`
2. Select service
3. Pick date (calendar)
4. Choose time slot
5. Select stylist
6. Enter details
7. Review summary
8. Proceed to payment

### Test Payment
1. Enter booking page
2. Proceed to `/payment`
3. See order summary
4. Select payment method:
   - EasyPaisa → See instructions
   - JazzCash → See USSD guide
   - Bank → See transfer details
   - Cash → See confirmation
5. Click confirm
6. See success message

### Test Authentication
1. Go to `/register`
2. Create new account
3. Go to `/login`
4. Login with credentials
5. See "Book Now" in navbar
6. Check auth context
